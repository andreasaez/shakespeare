# Contributions

Shakespeare is a personal project, and I'm not accepting pull requests, feature requests or other contributions.

You're welcome to **fork it** and make it your own. It's MIT licensed: change the colourways, badges, fonts or anything else, and install your own build (`make install`). See the README.

If you find a **security problem**, please report it privately as described in [SECURITY.md](SECURITY.md) rather than opening a public issue.
